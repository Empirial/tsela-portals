Readiness

What must be true before the demo

Important: today the app runs on built-in sample data held in each phone's memory, and sign-in accepts any email. A report on the driver's phone will not reach the manager's phone or the website. For this walkthrough to work live, the apps and website must share one real backend.

To build

  • Real backend with sign-in for the 5 accounts
  • Shared job data and live notifications between driver, manager, repairer
  • Owner dashboard reading the same data
  • Payment recorded (can be a simulated payment step for the demo)

To clean

  • Remove all sample trucks, drivers, jobs, invoices and mechanics
  • Keep only the 5 demo accounts plus Brave's truck(s)
  • Empty states look right on every screen

Checklist the day before

  • All 5 accounts can sign in
  • Driver is linked to a Brave truck
  • Both repairers approved and online
  • Location permission granted on phones
  • Phones charged, on good data or Wi-Fi
  • Owner dashboard open and signed in
  • One full dry run completed
  • Test data reset after the dry run
